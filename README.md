# ConsumerAdviceApi — .NET Console Application

Aplicação Console em C# (.NET) desenvolvida para consumir a API pública de conselhos aleatórios (`Advice Slip API`).

## 🚀 Funcionalidades

- Consome o endpoint HTTP `GET`: `https://api.adviceslip.com/advice`
- Deserializa o retorno JSON utilizando a biblioteca nativa `System.Text.Json`
- Exibe o conselho retornado no console formatado conforme a especificação.
